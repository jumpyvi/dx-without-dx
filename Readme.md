# UniversalBlue extra Justfiles (Community Edition)
> Experimental justfiles for atomic images

Run one of the available commands with `just -f {filename}.just --choose` in the repo root

# Available scripts

- VSCode devcontainer setup with podamn
- Rootfull virt setup with brew
- Rootless virt setup with flatpak
- Flatpak-Builder setup
- Rootfull docker setup with brew
- Buildstream setup
